--------------------------------------------------------------------------------
ROOT CAUSE ANALYSIS
--------------------------------------------------------------------------------

The original design used GENEROUS spacing (large padding/gaps).
Tailwind's default spacing scale is MORE COMPACT.

When migrating, Tailwind classes were applied without matching the original
spacing values, resulting in a systematically tighter layout.

This is NOT a bug - it's a spacing scale mismatch.
